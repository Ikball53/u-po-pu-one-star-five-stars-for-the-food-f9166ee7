# One Star, Five Stars for the Food

Entry for make.fun competition
`u-po-pu-one-star-five-stars-for-the-food-f9166ee7`.

The brief asks for one sentence, at most 200 characters, in the voice of
an alien tourist giving planet Earth a one-star review while still
slipping in a real compliment about the food. Our sentence (162
characters):

> One star: the sky leaks with no refund policy, the locals worship
> glowing rectangles, and gravity never apologises — but the noodles
> were worth the crash landing.

`main.py` writes exactly that sentence (no trailing newline)
to `/output/entry.txt`, deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
